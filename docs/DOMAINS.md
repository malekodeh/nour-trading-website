# Domain Name Recommendations

Availability has **not** been checked. Search each one at a registrar (Cloudflare Registrar, Namecheap, Google Domains / Squarespace) before deciding.

| Priority | Domain | Why |
|---|---|---|
| 1 | **nourtrading.com** | Exact brand match. Possibly already registered, so check whether it's for sale. |
| 2 | **nourtradingusa.com** | Signals US base, easy to say aloud |
| 3 | **nourtradinginc.com** | Matches the legal name; common pattern when .com is taken |
| 4 | **nourglobal.com** | Short, broader positioning for future growth |
| 5 | **noursourcing.com** | Describes the service, which helps with SEO |
| Alt | **nourtrading.us** | US-specific extension, if the .com options are unavailable |

Tips:

- Prefer **.com**, since B2B buyers trust it most.
- Also register close variants (e.g. both nourtrading**usa**.com and nourtrading**inc**.com) and redirect them to the main domain.
- Use the same domain for email (e.g. `quotes@nourtradingusa.com`) through Google Workspace or Microsoft 365.
- After you choose, set `NEXT_PUBLIC_SITE_URL` and verify the domain in Resend so quote notifications send from it.
